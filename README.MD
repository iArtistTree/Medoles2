## Site web de la sérénissime république de Médoles

Créer par Eddy

Ce site web sert comme page d'information pour une micronation fictive. 
C'est une recréation d'un ancient projet disponible ici: 
https://github.com/iArtistTree/Medoles

### Site web
https://medoles.netlify.app/

## Lancer le projet
Pour utiliser le site web localement:

1. Aller dans le dossier « frontend » 
2. Executer la command « npm run dev »
